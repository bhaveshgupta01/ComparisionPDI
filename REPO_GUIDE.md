## What's NOT here (and why)

- **Per-run model checkpoints (`*.pt`)** — these live on HPC at `/scratch/bg2896/ComparisionPDI/outputs/{phase_c,phase_e_xl,phase_e1b,phase_e6}/`. They're not committed because of size (~30-100 MB per ckpt × 144 runs ≈ 6-15 GB) and Git LFS quota.
- **The full BindingDB Ki TSV (~64 MB)** — committed via Git LFS in the upstream repo (`dataset/BindingDB/BindingDB_PDSPKi.tsv`).
- **The trained tokenizer vocabularies** — committed in the HPC `dataset/BindingDB/processed/smiles_vocab.json`.
- **HPC sbatch logs (`logs/*.out`, `logs/*.err`)** — kept on HPC only; not useful for the paper.

## Glossary

- **DTI** — Drug-Target Interaction. The task of predicting whether a small molecule binds a protein and how strongly.
- **pKi** — `−log₁₀(Ki / 10⁹)`. Higher = stronger binding. Our regression target.
- **CI** — Concordance Index. Probability that the model orders two random pairs correctly. 0.5 = chance, 1.0 = perfect.
- **CKA** — Centered Kernel Alignment. Measures similarity between two sets of representations.
- **Cold split** — Train / test split where some entity (drug or target) in the test set is *never* seen during training. Tests generalization.
- **Phase A / B / C / D / E** — Project phases (in chronological order):
  - A: per-owner Phase A sweeps (~22 configs each, fast 10k subset).
  - B: fair-config negotiation (locking shared hyperparameters).
  - C: full controlled comparison at d=128, 36 runs.
  - D: deep mechanistic extraction on Phase C checkpoints (Apr 29).
  - **E**: post-poster scale-up — E1 (d=256), E1b (d=192), E4 (causal ablations), E5 (mask-aware entropy), E6 (depth-axis).
